1. Введение

Задача подсчёта числа пар соседних элементов в векторе, для которых vec[i] > vec[i+1], является базовой операцией анализа последовательностей. При больших объёмах данных последовательная обработка может занимать значительное время. Использование параллельных вычислений с помощью MPI позволяет распределить работу между процессами и ускорить вычисления.

В данной работе реализованы две версии алгоритма:

Последовательная (SEQ) - для базовой проверки и сравнения производительности

Параллельная (MPI) - с распределением данных между процессами

Цель работы: реализовать корректные версии алгоритма, проверить их функциональность и оценить ускорение на разных количествах процессов.

2. Постановка задачи

Входные данные: Вектор целых чисел vec длины N

Выходные данные: Целое число viol — количество пар (i, i+1), где vec[i] > vec[i+1]

Ограничения: N ≥ 0

Должны учитываться граничные элементы процессов

Алгоритм должен работать корректно при N < P (процессов больше, чем элементов)

3. Базовый алгоритм (последовательный)

Последовательная реализация (ErmakovANumbViolElemVecSEQ) выполняет один проход по вектору:

1. Инициализировать viol = 0
2. Для i = 0..N-2:
     Если vec[i] > vec[i+1], то viol++
3. Вернуть viol


Сложность: 

Временная: O(N) // один проход по вектору

Пространственная: O(1) // вектор не хранится в памяти 

4. Схема параллелизации (MPI)
Разделение данных

Вектор делится на P частей, каждая часть передается своему ранку:

base = N / P
remainder = N % P
cnt[i] = base + (i < remainder ? 1 : 0)
disp[i] = смещение начала блока в векторе

Локальные вычисления

Каждый ранк подсчитывает количество нарушений в своём блоке.

Обработка границ

Для границы между соседними блоками:

Если последний элемент левой части больше первого элемента правой части, добавляется 1 к счётчику нарушений.

Агрегация результатов

MPI_Reduce(..., MPI_SUM, root=0):

Выполнение глобальной редукционной операции (например, сумма, максимум) по всем процессам.
Вычисление общей суммы значений, распределенных по процессам.
Может рассматриваться как операция, обратная широковещательной рассылке.

MPI_Bcast - Отправка данных из одного процесса всем остальным процессам.

Схема MPI:

Процесс 0: [0..chunk_0] -> local_viol_0  ─┐
Процесс 1: [..chunk_1..] -> local_viol_1 ├─ MPI_Reduce(SUM) -> total_viol
Процесс 2: [...] -> local_viol_2          ┘

task_run (seq)
